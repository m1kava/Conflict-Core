# First complete playable milestone

**Status: playable.** Verified by automated tests (simulation, server integration with real WebSocket clients)
and by headless-browser runs that play through the real UI.

| Requirement | Delivered |
|---|---|
| 1 original map | *Ashfall Crossing*: plateau bases with cliffs and ramps, river with a bridge and two fords, expansions, hills, forests |
| 2 real players online | Quick Match and private rooms (code / invite link); also AI opponents |
| 1 playable faction | Halcyon Accord |
| 6–10 units | 8: engineer, rifle squad, AT team, supply truck, recon vehicle, main battle tank, AA vehicle, SPG |
| 5–8 structures | 7: HQ, Power Plant, Supply Depot, Barracks, Vehicle Plant, Guard Tower, Radar Uplink |
| Economy | Supply fields, trucks, credits, power |
| Base construction | Engineers, placement preview, construction, repair, sell |
| Combat | Armor/damage matrix, turrets, projectiles, missiles, artillery, splash, veterancy |
| Fog of war | Server-enforced; explored/visible overlay; structure ghosts |
| Win/loss | Destroy critical structures and engineers, or surrender; results screen with stats |
| Mobile controls | Touch gestures, safe-area aware HUD, touch action buttons |
| Professional basic UI | Menus, lobby, HUD, minimap, command card, settings, results |
| Server-authoritative multiplayer | Yes — clients only send commands |

Open items before calling it polished: real-device frame-rate profiling, more model and animation detail, music.
